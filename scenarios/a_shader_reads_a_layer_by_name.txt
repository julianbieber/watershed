# Read another field from a shader by naming it in the file, from outside the process:
# `ridges`' `height` is one shader node whose file binds `base` with `// @layer base`,
# and the read is reported by `observe nodes`, `observe shaders` and `observe fields`
# with no reference node in the graph.
#
# Run with:  just drive run scenarios/a_shader_reads_a_layer_by_name.txt
#
# The file edits that go with this — an `@layer` naming no field, and one that makes
# `base` and `height` read each other — are not in this file: replay cannot edit a
# shader file, so they are pinned by the unit tests in `bake.rs` instead.

observe log

fixed-delta 1/60

new 256 256 7 ridges
wait bake

# `height` is one shader node on `mountains_over_base.wgsl`, and no node is a `fieldref`.
observe nodes

# Per file, the layers it reads by name: `mountains_over_base.wgsl` reads `base` at
# binding 3, and no other file reads one.
observe shaders

# `height` reads `base`, so `base` is baked before it, and no field carries a fault.
observe fields

# Both ends of the read, and both fields baked.
field height
observe field
field base
observe field

observe log
