# Read another layer from a shader by naming it in the file, from outside the process:
# `ridges`' `height` is the file `height.wesl`, which binds `base` with
# `// @layer base`, and the read is reported by `observe shaders` and `observe layers`.
#
# Run with:  just drive run scenarios/a_shader_reads_a_layer_by_name.txt
#
# The file edits that go with this — an `@layer` naming no layer, and one that makes
# `base` and `height` read each other — are not in this file: replay cannot edit a
# shader file, so they are pinned by the unit tests in `bake.rs` instead.

observe log

fixed-delta 1/60

new 256 256 7 ridges
wait bake

# Per file, the layers it reads by name: `height.wesl` reads `base` at binding 3, and
# no other file reads one.
observe shaders

# `height` reads `base`, so `base` is baked before it, and no layer carries a fault.
observe layers

# Both ends of the read, and both layers baked.
layer height
observe layer
layer base
observe layer

observe log
