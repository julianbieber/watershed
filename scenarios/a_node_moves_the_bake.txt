# Edit a field's graph from outside the process and watch the bake follow it.
#
# Run with:  just drive run scenarios/a_node_moves_the_bake.txt
#
# What makes this reproducible is that an edit holds its reply until the re-bake it
# provoked has landed — `node` and `set` answer when the document is settled, not when the
# graph changed. Nothing below counts frames.

# Before anything else: did the run complain? A shader that failed to compile draws nothing
# rather than drawing wrong. `observe log` drains, so this must come before any other call
# to it or the startup errors are already gone.
observe log

fixed-delta 1/60

# 256 square, and fitted — so the visible rectangle a live re-bake covers is the whole
# document, which is what lets `observe field` below be a statement about all of it rather
# than about the part that happened to be on screen.
new 256 256 7 continents
wait bake
zoom fit

# The graph as the preset built it, and the field it bakes. Both are the "before" the rest
# of this scenario is measured against. `continents` builds height as one node, n0, a
# `continents.wgsl` shader, and that node is the output.
observe nodes
observe field

# A stock shader copied into the document's shader directory, so a node can name it.
shader adopt mountains.wgsl

# A node added on its own changes nothing: nothing reaches it, so it is evaluated never.
# The field below has to be identical to the one above.
node add height shader mountains.wgsl
observe field

# Wiring n0 into the one pin of n1 is the edit that moves the bake. Wiring the output into
# a node nothing reads carries the output onto it, so `output` has to read n1 here, before
# any `node output` names it — and `baked` has fallen from `whole` to `rect`, because a
# live re-bake covers what is on screen and says so.
node connect height n0 n1 0
observe nodes
observe field
observe document

# A shader node's parameter, one at a time, without rewriting the node around it.
set height.n1.ridge 1.2
observe field

# Bypassing passes the first input straight through, so the field has to come back exactly
# to the numbers n0 baked before n1 was wired in.
node bypass height n1 on
observe field

node bypass height n1 off
capture /tmp/watershed-scenario/node-added.png

# A name is an address: once a node has one, every path that named it by id names it by
# name too, and both reach the same node.
node name height n1 peaks
set height.peaks.ridge 0.3
observe nodes
observe field

# Unwiring rather than deleting. Pointing the output back at n0 leaves n1 in the document
# but out of the walk, so the field returns to the numbers at the top of this run.
node output height n0
observe field

# And removing it leaves the graph the preset built.
node rm height n1
observe nodes
observe field

# The edge that would make the graph feed itself is deliberately not tried here: a
# scenario stops at its first refusal, and that one is expected. It is pinned instead by
# `an_edge_that_would_close_a_cycle_is_refused` in `edit.rs`, where the refusal can be
# asserted rather than ending the run.

# Dragging a card and naming a node are document edits that reach no bake, so neither may
# re-bake anything: `baked` has to be what it was before these two lines.
node place height n0 240 120
node name height n0 ground
observe document

# A field property rather than a node's. A shift changes the raster the field is written
# onto, so it is the one edit that discards the bake rather than patching it.
set moisture.shift 3
observe nodes

# Water is refused while the document is only part baked, because a drainage network solved
# against a stale height is wrong everywhere the height moved. `bake` is what answers that,
# and it is the whole document rather than the view.
bake
observe document
solve-water
wait water
observe water

# Solve, edit, solve again. An edit invalidates the water it produced but not the water
# spec, so both solves below have to answer with water, and with *different* lake counts,
# since the height under them moved. A named node is still addressable by its id.
#
# There is no `bake` here and none is needed: a solve bakes the whole document first when
# it has to.
set height.n0.land_scale 0.002
solve-water
observe water

set height.n0.relief 0.3
solve-water
observe water

# Close up on one corner. The re-bake covers the visible rectangle, so panning somewhere
# that has not been baked since the last edit has to bring it up to date on its own.
pan 64 64
zoom 96
observe view
observe document
capture /tmp/watershed-scenario/corner.png

# And again at the end, for anything the editing, baking and capturing provoked.
observe log
