# Rename a field and take one out from outside the process, and watch what named them
# follow: the references that read the renamed field, the water spec that solves over
# it, and the field list a removal leaves behind — from `observe nodes`, `observe water`
# and `observe document` rather than from a person clicking Rename and looking.
#
# Run with:  just drive run scenarios/a_field_is_renamed_and_removed.txt
#
# The refusals the task also names — a name already taken, a blank name, removing a
# field something reads, removing one the water spec names — are not in this file:
# replay stops at the first failure, so they are pinned by the unit tests in `edit.rs`
# instead, the way `a_field_is_added_from_the_socket.txt` leaves its two refusals there.

observe log

fixed-delta 1/60

# `ridges` builds `moisture`, `base` and `height`, with `height`'s shader file reading
# `base` by name — which is what makes the rename below worth watching.
new 256 256 7 ridges
wait bake
zoom fit

# The "before": three fields, and a water spec over `height` and `moisture`.
observe document
observe water

# The quantiles before the rename. `height` is what reads the field about to be renamed,
# so it is the field the rename leaves behind.
field height
observe field

# The rename itself. A rename cannot rewrite a file, so `height`'s file still names
# `base`, which is gone: `height` is left unbaked with that fault, while the rest bakes.
field rename base continent
wait bake
observe nodes
field height
observe field
observe document

# One undo step: `base` comes back, and `height` bakes again.
undo
wait bake
observe nodes

# And the redo puts the new name back on it, faulting `height` again.
redo
wait bake
observe nodes

# Undo once more, so `base` is named again and `height` is baked before it is renamed
# and water is solved over it.
undo
wait bake

# A rename of the field the water spec solves over. The spec follows the name, so the
# solve still has a field to read.
field rename height elevation
wait bake
observe water
solve-water
observe water
field elevation
observe field

# With the water gone, nothing names `moisture` any more and it can be taken out.
reset-water
field rm moisture
observe document

# One undo step for the removal too: the field comes back with the graph it had.
undo
wait bake
observe document
redo
wait bake
observe document

# A round trip through the terrain directory. `base` and `elevation` are the names that
# were written, so they are what comes back.
save /tmp/watershed-scenario/renamed-field
load /tmp/watershed-scenario/renamed-field
observe document
observe nodes

# And again at the end, for anything the saving and loading provoked.
observe log
