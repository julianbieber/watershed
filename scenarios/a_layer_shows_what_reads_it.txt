# Read the dependency between layers from outside the process, both ways round: what a
# layer reads and what reads it, from `observe layer` rather than from a person looking
# at the two rows the panel now carries. The same relation the canvas draws a reference
# card from and the panel's buttons open a layer through.
#
# Run with:  just drive run scenarios/a_layer_shows_what_reads_it.txt

observe log

fixed-delta 1/60

# `ridges` builds `moisture`, `base` and `height`, with `height`'s shader file reading
# `base` by name.
new 256 256 1 ridges
wait bake

# The reading end: `height` reads `base`, and nothing reads `height`.
layer height
observe layer

# The read end of the same edge: `base` is read by `height`, and reads nothing itself.
layer base
observe layer

# And a layer at neither end, which reports both lists empty rather than omitting them.
layer moisture
observe layer

# Back to `height`, where the panel's `reads` row has `base` under it.
layer height
observe layer

observe log
